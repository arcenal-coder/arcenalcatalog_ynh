# Catalogue ARCenal pour YunoHost

[![Installer le catalogue ARCenal avec YunoHost](https://install-app.yunohost.org/install-with-yunohost.svg)](https://onyx-ingenierie.com/yunohost/admin/#/apps/install-custom/https:%2F%2Fgithub.com%2Farcenal-coder%2Farcenalcatalog_ynh%2F)

Ce paquet ajoute le catalogue applicatif ARCenal à YunoHost. Après cette installation unique, les applications ARCenal sont installables et mises à jour depuis l’administration YunoHost.

## Réparation d'une installation antérieure

Si ARCenal Portail est déjà installé mais n'apparaît plus dans la liste des applications, désinstallez uniquement **Catalogue ARCenal**, puis réinstallez-le avec le bouton ci-dessus. Le connecteur corrige automatiquement les anciens numéros de version bêta. Le portail, ses paramètres et ses données ne sont pas supprimés.
